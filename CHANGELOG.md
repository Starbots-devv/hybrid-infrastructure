# Changelog

## 0.1.0a0 — first public alpha

- `sb-hybrid` CLI with versioned input contracts, deterministic offline comparison and a 13-section dossier in JSON, Markdown, printable HTML and CSV.
- 36-month FinOps plans with separate cash and allocated TCO views, growth, tiers, promotions, FX, asset depreciation, break-even and one-variable sensitivity thresholds.
- Three complete synthetic example flows and a starting bundle.
- Exact-subject verification of Starbots Security Skills reviews without importing that package.
- Agent Skill for Claude Code, Codex and Kiro (`skills/hybrid-infrastructure`).
- Optional in-memory SQS simulation with signed approvals, a hash-chained local journal and replay protection; real AWS mode is always denied.
